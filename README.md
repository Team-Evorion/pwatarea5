
# 📚 Biblioteca PWA

Sistema de Gestión de Biblioteca Online desarrollado como proyecto académico para la asignatura de **Programación Web Avanzada**.

## 📌 Descripción

Aplicación web que permite administrar libros, usuarios, préstamos y devoluciones mediante una interfaz moderna, intuitiva y adaptable a diferentes dispositivos.

El sistema cuenta con tres roles: administrador, bibliotecario y lector, cada uno con sus respectivos permisos y funcionalidades.

## 🛠️ Tecnologías utilizadas

- PHP y Laravel 12
- MySQL
- HTML5, CSS3 y JavaScript
- Blade
- Bootstrap 5
- Vite

## ⚙️ Funcionalidades

- Registro e inicio de sesión.
- Gestión de usuarios y roles.
- Administración de libros (CRUD).
- Subida y visualización de portadas.
- Registro de fechas históricas (a. C. y d. C.).
- Control de ejemplares disponibles.
- Gestión de préstamos y devoluciones.
- Historial de préstamos por usuario.
- Paneles personalizados según el rol.
- Diseño responsive.
